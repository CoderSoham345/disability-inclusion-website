## 📞 Support & Troubleshooting

### Common Questions

**Q: Can I edit the files?**
A: When shared as "Viewer", files are read-only. You can download and edit locally, or contact data owner for editable copy.

**Q: What if the Google Drive link doesn't work?**
A: Verify sharing is enabled, permission is "Viewer" or higher, and wait 2-3 minutes for changes to propagate.

**Q: Can I convert Excel to Google Sheets?**
A: Yes! Right-click file → Open with → Google Sheets. Recommended for online collaboration.

**Q: How often is data updated?**
A: Databases recommended for quarterly updates to athlete achievements and social metrics.
