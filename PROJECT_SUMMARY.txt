STEP 2: Create Google Drive Folder
   • Visit drive.google.com
   • Click New → Folder
   • Name: "Disability Inclusion Through Sports India - Databases"

STEP 3: Upload Excel Files
   • Upload 4 Excel files to folder:
     - Disability_Sports_India_Complete_Database.xlsx
     - Disability_Sports_NGO_Database.xlsx
     - Disability_Sports_Paralympians_Database.xlsx
     - Disability_Sports_Collaboration_Database.xlsx

STEP 4: Enable Viewer Access
   • Right-click folder → Share
   • Change to "Anyone with the link"
   • Select "Viewer" (read-only) permission
   • Copy generated link

STEP 5: Test Link
   • Open link in incognito window
   • Verify all files accessible
   • Ensure no login required

STEP 6: Submit
   • Paste Google Drive link
   • Verify format: https://drive.google.com/drive/folders/[ID]?usp=sharing
   • Submit as required
