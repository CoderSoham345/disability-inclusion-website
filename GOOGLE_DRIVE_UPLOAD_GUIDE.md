## Step-by-Step Google Drive Upload Instructions

### Method 1: Upload Excel Files Individually

**Step 1: Prepare Files**
1. Ensure you have downloaded all 4 Excel files from the project directory
2. Keep original filenames for easy identification

**Step 2: Create Google Drive Folder**
1. Go to [Google Drive](https://drive.google.com)
2. Sign in with your Google account
3. Click "+ New" → "Folder"
4. Name the folder: "Disability Inclusion Through Sports India - Databases"
5. Note the folder ID from the URL (format: /folders/[FOLDER_ID])

**Step 3: Upload Files**
1. Open the new folder
2. Click "Upload files" or drag and drop
3. Select all 4 Excel files:
   - Disability_Sports_India_Complete_Database.xlsx
   - Disability_Sports_NGO_Database.xlsx
   - Disability_Sports_Paralympians_Database.xlsx
   - Disability_Sports_Collaboration_Database.xlsx
4. Wait for upload to complete

**Step 4: Enable Viewer Access**
1. Right-click the folder → "Share"
2. In the sharing dialog:
   - Click "Change to anyone with the link"
   - Select "Viewer" (read-only access)
   - Ensure "Link sharing is on"
3. Click "Copy link"
4. Paste in a safe location (this is your shareable link)

**Step 5: Share Individual Files (Optional)**
For specific file access:
1. Right-click each Excel file
2. Click "Share"
3. Select "Viewer" access
4. Copy individual file links as needed

---

### Method 2: Import as Google Sheets (Recommended for Collaboration)

**Step 1: Upload Excel Files**
1. Follow Steps 1-3 above

**Step 2: Convert to Google Sheets**
1. Right-click the first Excel file
2. Select "Open with" → "Google Sheets"
3. A new Google Sheet is created (linked to the original Excel)
4. Rename the sheet: "[Database Name] - View Only"
5. Repeat for other Excel files

**Step 3: Organize in Shared Folder**
1. Create a shared folder as in Method 1
2. Move all converted Google Sheets into the folder
3. Keep original Excel files for download backup

**Step 4: Set Sharing Permissions**
1. Right-click the folder → "Share"
2. Choose sharing method:
   - **For specific people**: Add email addresses, select "Viewer"
   - **For public link**: Click "Change to anyone with the link" → "Viewer"
3. Copy and share the folder link

## Google Drive Sharing Link Template

Once uploaded and shared, your link should look like:

**Folder Link Format**:
```
https://drive.google.com/drive/folders/[FOLDER_ID]?usp=sharing
```

**Example**:
```
https://drive.google.com/drive/folders/1A2B3C4D5E6F7G8H9I0J1K2L3M4N5O6P?usp=sharing
```

**Verification**:
- Anyone with the link can access
- They can only VIEW (not edit)
- No login required for access

## Access Control & Sharing Options

### Viewer Access (Recommended)
- Users can VIEW files
- Users can DOWNLOAD files
- Users can COMMENT (optional)
- Users CANNOT edit or change data
- Most secure for databases

**Setup**:
1. Share folder/file
2. Select "Viewer" permission
3. Share via link or specific emails

### Commenter Access
- Users can VIEW, COMMENT
- Users can DOWNLOAD
- Users CANNOT edit
- Good for feedback collection

**Setup**:
1. Share folder/file
2. Select "Commenter" permission
3. Include note: "Please use comments for feedback"

### Editor Access (Not Recommended for Master Database)
- Users can VIEW, EDIT
- Useful only for collaboration teams
- Create duplicate copy if needed

## Troubleshooting

### Link Not Working
- Ensure "Link sharing is on"
- Verify permission is "Viewer" or higher
- Copy link from share dialog, not URL bar
- Test in incognito window
- Wait 2-3 minutes after changing permissions

### Can't Upload Files
- Check file size (all files <20 MB)
- Ensure sufficient Google Drive storage
- Try uploading one at a time
- Use Chrome browser
- Clear browser cache and retry

### Permission Issues
- Verify you own/have access to folder
- Check that sharing is enabled
- Remove and re-add sharing settings
- Create new folder and copy files

### Data Not Displaying
- Ensure Excel files are properly formatted
- Try opening in Google Sheets instead
- Download original Excel file to verify data
- Check for special characters in field names
